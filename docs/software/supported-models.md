# Supported models

After this page you know where to find the models the studio can use to write code from your description.

## Three ways to run the generator

**Generator settings** offers **Free (built-in)**, **Use your own key** and **Use my credits**. Credits are rolling out. See [Free use, credits and privacy](credits.md) for costs, limits and setup.

Free and credit generations use the models the studio lists.

## Use your own key

An API key is a secret code that lets the studio use your account with a provider. With **Use your own key**, the **Provider** choices are **Anthropic**, **OpenAI** and **Google Gemini**.

The settings link to each provider's key page through **Get a free key**. **Refresh model list** asks the provider which models your key can use.

See [Choosing a model](ota-builder.md#choosing-a-model) for where to choose in the studio.
