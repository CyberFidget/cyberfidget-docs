# Sharing

Share creates a link to a snapshot of your work. It does not follow later edits automatically.

| Capability | Desktop / laptop location | Phone today | Shortcut | Touch equivalent |
|---|---|---|---|---|
| Share the project | Share in the project bar | Share control in the project header | None | Tap Share. |
| Share this sprite | Right-panel footer, above version controls | Below Layers, above version controls | None | Tap Share this sprite. |

Phone placement will change. The current phone editor has its sprite-sharing button in the stacked editor content, rather than a Files sheet.

For the sharing dialog, sending a link, copying permissions and stopping a link, follow [Share a link](../software/import-export.md#share-a-link). For an editable file instead of a viewing link, see [Files and versions](files-and-versions.md).
