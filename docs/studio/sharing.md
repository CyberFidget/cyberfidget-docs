# Sharing

Share creates a link to a snapshot of your work. It does not follow edits you make after sharing.

| Capability | Desktop / laptop location | Phone | Shortcut | Touch equivalent |
|---|---|---|---|---|
| Share the project | Share in the project bar | Share control in the project header | None | Tap Share. |
| Share this sprite | Right-panel footer, above version controls | Top of the Files sheet (tap the Files chip) | None | Tap Share this sprite. |

For the sharing dialog, sending a link, copying permissions and stopping a link, follow [Share a link](../software/import-export.md#share-a-link). For an editable file instead of a viewing link, see [Files and versions](files-and-versions.md).
