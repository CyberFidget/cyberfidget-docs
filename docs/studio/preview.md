# Preview and Speed

**Preview · live** shows how the drawing appears on the device's screen. On desktop and laptop it is at the top of the right panel. A phone has no separate preview panel: **Play**, in the bar below the canvas, loops the current animation on the canvas itself and stops when you tap **Stop** or the canvas. Playing is a view only and never changes your art.

| Control | What it does | Shortcut | Touch equivalent |
|---|---|---|---|
| Preview canvas | Show the current picture or playing animation. | None | Not shown on a phone; use Play. |
| Device | Toggle between the flat screen preview and a device mockup. | None | Desktop and laptop only. |
| Play / Pause | The preview plays automatically. Use the Play / Pause button to stop and restart it. | None | Tap Play in the bar below the canvas; it plays the canvas and changes to Stop. |
| Speed | Change frame timing with the slider. | None | Open the Frames sheet (tap the Frames chip) and drag Speed. |

Frame rate means the number of pictures shown each second. The **Speed** readout shows this as, for example, `6/sec`. At 166 milliseconds (ms) per frame, that is about six frames a second. A shorter duration plays faster.

Speed sets both playback and the saved frame durations. Move it right to play faster. Saving imported art without changing Speed keeps its original per-frame timing.

To loop one named animation, use its Play button in the [timeline](animations-and-frames.md). To save a playable image file, use [Download animation](files-and-versions.md).
