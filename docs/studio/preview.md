# Preview and Speed

**Preview · live** shows how the drawing appears on the device's screen. On desktop and laptop it is at the top of the right panel. On a phone it remains a separate preview below the canvas footer, before Layers; playback does not replace the editing canvas.

| Control | What it does | Shortcut | Touch equivalent |
|---|---|---|---|
| Preview canvas | Show the current picture or playing animation. | None | View the separate preview; no gesture is required. |
| Device | Toggle between the flat screen preview and a device mockup. | None | Tap Device next to the heading. |
| Play / Pause | The preview plays automatically. Use the Play / Pause button to stop and restart it. | None | Tap the Play / Pause button below the preview. |
| Speed | Change frame timing with the slider. | None | Drag Speed below the preview. |

Frame rate means the number of pictures shown each second. The **Speed** readout shows this as, for example, `6/sec`. At 166 milliseconds (ms) per frame, that is about six frames a second. A shorter duration plays faster.

Speed sets both playback and the saved frame durations. Move it right to play faster. Saving imported art without changing Speed keeps its original per-frame timing.

To loop one named animation, use its Play button in the [timeline](animations-and-frames.md). To save a playable image file, use [Download animation](files-and-versions.md).
