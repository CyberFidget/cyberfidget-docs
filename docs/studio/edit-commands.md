# Edit commands

On desktop and laptop, **Edit** stays at the right end of the options bar above the canvas. On a phone today it is in the wrapping options row above the canvas. Tap **Edit**, then a command. Phone placement will change.

The table gives keyboard and touch equivalents. **None** means no dedicated shortcut. Ctrl commands also accept Command on a Mac. Commands can be disabled when they have nothing to act on.

| Command | What it does | Shortcut | Touch equivalent |
|---|---|---|---|
| Copy | Copy selected pixels into the editor's clipboard. | Ctrl+C | Tap Copy in Edit or Select / Select oval options. |
| Cut | Copy selected pixels and remove them from the drawing. | Ctrl+X | Tap Cut in Edit or selection options. |
| Paste | Insert copied pixels into the current frame. | Ctrl+V | Tap Paste in Edit or selection options. |
| Paste to all frames | Insert the clipboard pixels across the sprite's frames. | None | Tap Paste to all frames in Edit or selection options. |
| Erase selection | Remove selected pixels without copying them. | Delete or Backspace | Tap Erase selection in Edit or selection options. |
| Flip left-right | Reverse the selection, or layer if nothing is selected, horizontally. | None | Tap in Edit, or Transform > Flip & rotate. |
| Flip up-down | Reverse the selection or layer vertically. | None | Tap in Edit, or Transform > Flip & rotate. |
| Rotate 90° clockwise | Turn the selection or layer a quarter turn clockwise. | None | Tap in Edit, or Transform > Flip & rotate. |
| Resize... | Open a dialog to resize the selection, or whole layer when nothing is selected. | None | Tap Resize... in Edit. |
| Clear layer | Remove all pixels from the active layer. | None | Tap Clear layer in Edit or the layer's **...** menu. |
| Guide box | Open a drawing-area guide dialog. | None | Tap Guide box in Edit or the canvas footer. |
| Grid | Show or hide pixel boundaries without altering art. | None | Tap Grid in Edit or the canvas footer. |

## Resize pixels

In **Resize...**, choose **50%**, **150%**, **200%** or **300%** for a preset. For another percentage, choose **Custom**, enter **Resize (%)**, then **Apply**. **Keep proportions** preserves the width-to-height ratio. These controls have no dedicated keyboard shortcuts; on a phone tap the preset or type the percentage and tap Apply. **Close** dismisses the dialog. Resize changes the art; [zoom](view.md) changes only its display.

## Undo and Redo

**Undo** reverses the latest edit; **Redo** reapplies an undone edit. They are at the bottom of the desktop/laptop tool bar. On a phone today they sit with the wrapping tools above the options and canvas. Tap the buttons for touch access. Use **Ctrl+Z** for Undo and **Ctrl+Y** or **Ctrl+Shift+Z** for Redo. The explicit Redo button is the dependable alternative to keyboard combinations.

There is no two-finger-tap Undo gesture in the current editor. Two fingers control the [view](view.md).
