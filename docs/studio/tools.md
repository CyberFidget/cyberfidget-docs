# Tools

Open a sprite in Studio's **2D** workspace. A sprite is an image or animation for an app. The canvas is the 128 by 64 pixel drawing area; edits affect the active layer of the selected frame.

On desktop and laptop, all twelve tools are in the tool bar to the left of the canvas. On a phone, all twelve are in wrapping rows above the options and canvas. Tap a tool to select it, then use the touch action below.

Keyboard letters work while the editor has focus, outside text fields. For commands using Ctrl, a Mac can use Command. **None** means there is no dedicated keyboard shortcut.

| Tool | What it does / mouse action | Shortcut | Touch equivalent |
|---|---|---|---|
| Draw | Click or drag to turn pixels on. | D | Tap or drag on the canvas. |
| Brush | Paint with a configurable tip, size and flow (how densely pixels are painted). | P | Drag on the canvas. |
| Erase | Remove pixels with a configurable size and flow (how densely pixels are removed). | E | Drag over pixels. |
| Fill | Fill a connected enclosed area. | G | Tap inside the area. |
| Line | Drag from the start to the end of a straight line. | L; Shift snaps angles | Drag between endpoints; enable **Snap angles** to constrain direction. |
| Rectangle | Drag to draw a rectangular outline or filled shape. | None; Shift makes a square | Drag opposite corners; enable **Square** for equal sides. |
| Oval | Drag to draw an oval outline or filled shape. | None; Shift makes a circle | Drag the bounds; enable **Circle** for equal width and height. |
| Select | Drag a box around pixels for clipboard or arrangement commands. | S | Drag a selection box. |
| Select oval | Select pixels inside oval bounds. | None | Drag an oval selection. |
| Move | Move the selected pixels, or the layer when nothing is selected. | M; arrow keys nudge | Drag the pixels, or tap the **Nudge** arrows in options. |
| Transform | Resize or arrange pixels using handles around the selection or layer. | T; Enter applies; Esc cancels | Drag handles; tap **Apply** or **Cancel**. |
| Zoom | Enlarge the view without changing pixels. | Z; Alt-click zooms out | Tap to zoom in; enable **Zoom out** and tap to zoom out. |

Right-click on the canvas to erase pixels. On touch screens, select **Erase** and drag over the pixels.

Read [Tool options](tool-options.md) for settings, [Edit commands](edit-commands.md) for clipboard operations, and [View](view.md) for gestures and guides.
