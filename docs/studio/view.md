# View: zoom, grid and guide box

The viewport is the visible area of the canvas. View controls change how you see your work; they do not change the saved pixels.

On desktop and laptop, view controls sit in the canvas footer, below the canvas. On a phone, **Grid**, the zoom percentage and **Fit** are in the bar at the top of the 2D tab, beside the **Files** chip; there are no - / + buttons, so pinch to zoom. **Edit** also offers Grid and Guide box on every screen size.

| Control | What it does | Keyboard / mouse | Touch equivalent |
|---|---|---|---|
| - / + and zoom readout | Reduce or increase magnification; the percentage reports the current zoom. | - / + (or =); mouse wheel zooms | Tap - / +, or pinch with two fingers. |
| Fit | Fit the whole canvas into the available viewport. | Ctrl+Shift+J (Command on Mac) | Tap Fit in the top bar or Zoom options. |
| 100% | Return to the canvas's base display scale. | No dedicated shortcut | Tap 100% in the Zoom tool's options. |
| Zoom tool | Zoom around a point on the canvas. | Z, then click; Alt-click zooms out | Select Zoom and tap; check Zoom out for the reverse direction. |
| Pan | Move the view to reach art outside the visible area. | Drag with the middle mouse button; no dedicated keyboard shortcut | Move two fingers together on the canvas. |
| Grid | Toggle lines separating pixels. | No dedicated shortcut | Tap Grid in the top bar or Edit. |
| Guide box | Show a reference drawing area, measured in pixels. | No dedicated shortcut | Tap Guide box in Edit. |

## Set a guide

In **Guide box**, enter **Width** (1 to 128) and **Height** (1 to 64), then choose **Show guide**. **Remove guide** removes it; **Cancel** closes without applying the dialog changes. Tap these same fields and buttons on a phone; they have no dedicated keyboard shortcuts.

The guide isn't included in output. Select **Move**, then drag the guide to reposition it. When the guide is selected, arrow keys move it instead of nudging artwork; dragging it with Move is the touch equivalent.
