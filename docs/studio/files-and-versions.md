# Files and versions

On desktop and laptop, version controls, Download animation and the **Sprite file** menu sit in the right-panel footer. On a phone they are below Preview and Layers, before the timeline.

All controls below have no dedicated keyboard shortcut. Tap them on a touch screen; tap or type in the version-label field.

| Control | What it does | Desktop / laptop | Phone / touch |
|---|---|---|---|
| Label this version (optional) | Name a checkpoint so you can find it again. | Right-panel footer | Type in the field below Layers. |
| Save version | Record a checkpoint of the current drawing. | Right-panel footer | Tap Save version below Layers. |
| History | Open saved versions to compare and restore. | Right-panel footer | Tap History below Layers; tap Restore on an entry or Close to dismiss. |
| Save to My Assets | Save a reusable copy in your account library. | Right-panel footer | Tap below Layers and review the name in the dialog. |
| Download animation | Save an animated Graphics Interchange Format (GIF) image. This is a viewing file, not an editable Studio backup. | Right-panel footer | Tap Download animation below Layers. |
| Save to file | Save an editable `.cfsprite.json` sprite file. | Sprite file menu | Tap Sprite file below Layers, then Save to file. |
| Add from file | Add a sprite to the open project without replacing existing art. | Sprite file menu or Project Files | Tap the same menu command, or expand Project Files above the tools and tap Add from file. |
| Load demo | Load example art to explore the editor. | Sprite file menu | Tap Sprite file, then Load demo. |
| Project Files | List project sprites, including ones with closed editor tabs. **New sprite** adds a blank sprite; when the project has no sprites, the editor shows **No sprite open** with a **New sprite** button. | Library disclosure in the left sidebar | Tap Project Files above the tools, then an entry to open it. |

Export progress is shown while Download animation is working. It is a status readout with no keyboard shortcut or touch action; wait for completion before repeating the download.

To recover earlier work, use History or open a saved file. To keep a whole project, use the [whole-project backup](../software/import-export.md#keep-a-whole-project).

See [Drawing and version history](drawing-and-versions.md) for automatic checkpoints and the 20-version limit, [Your sprite library](your-sprite-library.md) for reusable copies, and [Keeping and sharing your work](../software/import-export.md) for file formats and imports.
